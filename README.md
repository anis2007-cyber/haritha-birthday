# Haritha's Animated Advance Birthday Website 💗

This website is a mobile-friendly, animated birthday experience from Anis to Haritha. It includes floating hearts and sparkles, page transitions, a candle-blowing moment, confetti, a gift reveal, the personal Tamil-English letter, and the supplied song.

## Preview locally
Keep `index.html` and `music.mp3` in the same folder, then open `index.html` in a browser. Music starts after the first interaction because browsers commonly block autoplay.

## Publish free with GitHub Pages
1. Create a GitHub repository.
2. Upload **both** `index.html` and `music.mp3` (and optionally this README) to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site and open the URL shown in Settings → Pages.

Keep the music file alongside `index.html` so the song works online.
